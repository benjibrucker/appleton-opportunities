How to navigate

  • Select a row or numbered pin for details. Numbers always mean regional ranks, even after sorting.
  • Use Results to return to your place in the list; arrows move through matching projects.
  • On phones, use the fixed Projects / Map tabs.
  • Show all frames the matching anchors. Shared pins have one colored, rank-labeled segment per record and open a chooser; locations are never offset to simulate separate sites.
  • Clear filters restores all records without changing your color or sort mode. CSV always exports all records, not only matches.

Ranking is a screening heuristic

Higher scores and lower rank numbers prioritize follow-up. These are not award probabilities, margin estimates, or bid/no-bid advice.

Recorded factor values, when supplied, appear in each project's ranking notes. High imagery priority is a separate prompt to inspect imagery—not the regional rank or a verified pavement condition.

Colors compare the same bands in every search

Five strong steps and a separate unknown gray use fixed thresholds. Timeline uses the start of the published range: 2027 / 2028 / 2029 / 2030 / 2031+. The full range remains visible; it is not reduced to a single precise construction date.

Budget uses the published lower bound: <$2M / $2–<$5M / $5–<$10M / $10–<$25M / $25M+. A $1M–$2M project is in the first band. Unknown values are never treated as zero. Regional-priority bands are ranks 1–10 / 11–20 / 21–30 / 31–40 / 41–50. Distance bands are 0–<15 / 15–<30 / 30–<50 / 50–<75 / 75+ miles.

Estimated budget ≠ Walbec revenue. Program budgets may cover broader scope, multiple packages or work by other contractors.

Program year ≠ open bid. Procurement status is not verified. Confirm current scope, letting, award, eligibility and available packages with the official source before pursuit.
Markers represent approximate corridor or community anchors—not construction limits, parcels, staging sites or bid-package boundaries. Verify the official project source before qualification.
